Project Description:
Develop an equivalent to Excel or Google Sheet application where the interaction with the application is a chat interaction.

Step 1: User loads a CSV file and the program will create an SQL database.

Step 2: Program uses the CSV file to make a table.

Step 3: Checks to see if a table is already existing and how the user would like to deal with it.

Step 4: While loop that will keep iterating to allow the user to perform commands as needed.

Step 5: Integerated OpenAI API to add an LLM component to project.

Insturctions to Run:

1.) Install Pandas, SQLITE, and OpenAI                                               
2.) Replace "YOUR_OPENAI_API_KEY" with your actual key
3.) Run script
4.) Load CSV
5.) Ask queries
